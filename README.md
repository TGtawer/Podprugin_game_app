# Арена дуэлей

Учебная браузерная игра на **TypeScript + Phaser + Vite**.

## О чём игра

Ты — синий квадрат на закрытой арене. Красные враги идут к тебе со всех сторон.
Чтобы выжить, не нужно стрелять: когда враг подходит вплотную, начинается **дуэль** на реакцию.
Нужно нажать **Q** и **E** в правильном порядке быстрее, чем истечёт время.
Проиграл дуэль или пропустил выстрел стрелка — теряешь здоровье.

## Цель

Продержаться **90 секунд** раунда и набрать как можно больше очков.
Очки даются только за победы в дуэлях.

- Здоровье стартует с **3** ударов. Упало до нуля — поражение.
- Время вышло — раунд закончился, показывается итоговый счёт.

## Управление

| Клавиша | Действие |
| --- | --- |
| **W A S D** / стрелки | Движение |
| **Space** | Рывок в направлении движения (тратит стамину) |
| **Q** / **E** | Ответ в дуэли |
| **Esc** | Пауза / продолжить |
| **R** | Рестарт после конца игры |

## Враги

| Враг | Вид | Особенность |
| --- | --- | --- |
| Обычный | маленький красный круг | короткая дуэль из 2 нажатий |
| Элитный | большой тёмно-красный круг | длинная дуэль из 5 нажатий |
| Стрелок | жёлтый треугольник | держит дистанцию и стреляет снарядами, стрелять перестаёт, пока убегает |

**Фазы раунда:** с начала и до **10 очков** появляются только обычные враги.
При 10 очках показывается баннер «Орда на подходе!» и начинают появляться элитные враги и стрелки.

## Как запустить

Нужен **Node.js >= 20.19**.

```bash
npm install
npm run dev
```

Открой в браузере адрес, который напечатает Vite (обычно `http://localhost:5173/`).

Production-сборка и локальная проверка:

```bash
npm run build
npm run preview
```

Проверка типов отдельно:

```bash
npm run typecheck
```

## Что уже реализовано

- движение игрока и удержание в пределах арены;
- стамина с восстановлением и рывок по Space;
- три типа врагов и спавн со всех краёв;
- дуэль на Q/E с ограничением времени, подсветкой клавиш и уроном при ошибке;
- стрелки: держат дистанцию, стреляют снарядами, не стреляют во время отступления;
- неуязвимость после урона и после победы в дуэли;
- таймер раунда, здоровье, очки и экран конца игры;
- двухфазный спавн: вторая фаза с 10 очков + уведомление «Орда на подходе!»;
- пауза на Esc (с заморозкой таймеров и дуэли);
- рестарт на R со сбросом всего состояния;
- все игровые параметры вынесены в [`src/game/config.ts`](./src/game/config.ts).
